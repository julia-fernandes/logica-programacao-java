# Exercícios de Lógica de Programação em Java

Repositório criado para praticar lógica de programação utilizando Java.

O objetivo é desenvolver o raciocínio lógico, a resolução de problemas e o domínio dos conceitos fundamentais da linguagem por meio de exercícios simples e progressivamente mais desafiadores.

## Conteúdo

* Estruturas condicionais
* Estruturas de repetição
* Funções e procedimentos
* Vetores
* Matrizes
* Arraylist


## Tecnologias

* Java
* IntelliJ IDEA
